# Oluwaseun Ojimi — Security Engineering Portfolio

A static, GitHub Pages-ready portfolio for showcasing Security Platform Engineering, Splunk Enterprise Security, detection engineering, SIEM architecture, AWS security telemetry, and automation work.

## Included

- `index.html` — portfolio homepage
- `projects/splunk-es-detection-lab.html` — first flagship case study
- `assets/styles.css` — responsive styling
- `PORTFOLIO_ROADMAP.md` — recommended case-study publishing order

## Before publishing

1. Replace `YOUR-GITHUB-USERNAME` in `index.html`.
2. Confirm the professional contact email you want visible publicly.
3. Add only sanitized screenshots and diagrams.
4. Never publish production IPs, hostnames, usernames, secrets, customer architecture, proprietary configs, or employer data.

## Publish with GitHub Pages

Create a public repository (suggested name: `security-engineering-portfolio`), upload these files, then enable GitHub Pages in repository settings.

A custom domain can be added later.

## Suggested repositories

- `security-engineering-portfolio`
