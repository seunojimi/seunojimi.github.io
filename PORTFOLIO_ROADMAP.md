## Case-study template
Every public project should answer:
- What problem was being solved?
- What environment was used?
- What was the architecture?
- What telemetry was required?
- How was the data normalized?
- What detection / platform logic was implemented?
- How was it validated?
- What false positives / tradeoffs were considered?
- What was the measurable outcome?
- What would you improve next?

## Publishing rule
Use only lab-generated or sanitized artifacts. Never publish employer/customer confidential information.
